# v0.1.0

This first pinned early-adopter release packages Backlot's CLI and local daemon,
native/container scenes, private retained state and explicit managed/external HTTPS.
Download targets are macOS ARM64 and Linux amd64 (Ubuntu 24.04 and Debian 13.4).
Caddy, Docker and system/browser trust stay explicit operator setup.

Release archives include `backlot`, LICENSE and dependency notices, with a separate
SHA-256 manifest. Every executable embeds the full project license and dependency
notices, available through `backlot licenses`; installation needs only the binary.
Version JSON identifies the tag, full revision and source time;
Go installations identify their resolved module version and revision when available.
Use exact `@v0.1.0` or versioned archive names after publication; `main`/`@latest`
are moving selections. Check the GitHub Release's exact tagged source for matching
[installation/upgrade guidance](https://github.com/octacian/backlot/blob/v0.1.0/docs/operations.md)
and [schemas](https://github.com/octacian/backlot/tree/v0.1.0/schemas).

Stop the old daemon with its matching binary and wait for exit before binary
replacement; start the new daemon explicitly. Preserve state and CA identity.
Forward state compatibility retains v9 as the baseline, with no reversible
migration/downgrade promise. This packaging change introduces no state-format or
wire/API change. Unsupported state is rejected unchanged for matching-binary
recovery. Prefer CLI/daemon from the same release.

The documented CLI/exit, JSON/local API, manifest/machine configuration and retained
upgrade contracts are preserved across v0.1.x patches. Breaking changes require a
new 0.x minor and migration notes; 1.0 stability is not claimed. Published tags and
assets remain fixed; defects require a new patch release.

Known limitations: Windows support, WSL verification, installers, bundled
dependencies, signing/notarization and self-updates are not included. Native
runtime diagnostics [#79](https://github.com/octacian/backlot/issues/79) and
[#81](https://github.com/octacian/backlot/issues/81) remain unresolved. See the tagged
[platform and supervision limits](https://github.com/octacian/backlot/blob/v0.1.0/docs/platforms.md).
